# Token Eater — Fake Locker Prank

Шуточный "локер" для розыгрыша друзей. Запускается одним `.bat` файлом, никаких реальных файлов не шифрует, ничего не удаляет и не портит — чистая анимация и актёрская игра в консоли.

> ⚠️ Это прикол, а не вредоносное ПО. Скрипт ничего не шифрует, не удаляет и не отправляет по сети. Используй только с согласия человека, на котором разыгрываешь — иначе антивирус (и человек) могут не оценить шутку.

## Что происходит

1. Окно консоли разворачивается на весь экран.
2. По центру экрана крутится ASCII-жук ("Token Eater" / жук-токеноед), набирая обороты.
3. Жук останавливается, замирает (отсылка к Годжо Сатору), щёлкает пальцами.
4. Экран заливает фиолетовым — вспышка "пустой техники".
5. Запускается поддельная загрузка Windows с бегущими хекс-ошибками и "UXCryptor".
6. Прогресс-бар "шифрования файлов" — реальный объём занятого места на диске `C:` и примерное число файлов.
7. Отдельная сцена: по центру экрана появляется глаз и надпись "ВАС ЗАМЕТИЛИ".
8. Красный экран со смертью (ASCII-жнец).
9. Синий экран поддельного локера с предложением ввести код разблокировки.

Код разблокировки зашит в `locker.ps1` — вводится прямо в консоли (ввод виден, без отдельных окон).

## Как запустить

```
fakelocker.bat
```

Запускать на Windows (используется `cmd.exe` + PowerShell, которые идут в системе по умолчанию). Администраторские права не нужны.

## Как это устроено технически

- `fakelocker.bat` — ASCII-анимация жука (спин, замедление, щелчок пальцами) через `cls` + `ping -w` вместо `timeout`/`sleep`, с ANSI-цветом через `prompt $E`.
- Вторая часть сценария (поддельная загрузка, прогресс-бар, сцена "ВАС ЗАМЕТИЛИ", экран смерти, локер с вводом кода) — отдельный PowerShell-скрипт `locker.ps1`, который `.bat` встраивает как base64-блок, разворачивает во временный файл и запускает.
- Все ANSI/Unicode-символы (стрелочки, braille-арт глаза, кириллица) живут только в `locker.ps1` — сам `.bat` остаётся чистым ASCII, чтобы не ловить проблемы с кодировкой `cmd.exe`.

## Файлы

- `fakelocker.bat` — точка входа, анимация жука, встроенный locker.ps1 в base64.
- `locker.ps1` — исходник второй части сценария (для правок; сам `.bat` уже содержит собранную копию).
